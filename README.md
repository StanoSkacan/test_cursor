# Animated Top Navigation Demo

Next.js demo aplikacia s fullscreen hamburger navigaciou, ktora sa po kliknuti
animovane vysuva zhora, prekryje cely layout a zobrazi polozky menu pod sebou.

## Spustenie

```bash
npm install
npm run dev
```

Aplikacia bude dostupna na `http://localhost:3000`.

## Skripty

- `npm run dev` - spusti vyvojovy server
- `npm run build` - vytvori produkcny build
- `npm run lint` - skontroluje projekt cez ESLint
